# Peripheral AUTO Control Center | 外设AUTO控制中心 v2.0.0

**By Nonori**

A lightweight Windows launcher for peripheral companion apps and audio settings.

## Download

Download **外设AUTO控制中心.exe** below and double-click to run. No installer required. Intended for Windows 11 with .NET Framework 4.x.

下载下方 EXE 即可运行，软件界面为中文。

## Highlights

- Discover peripheral apps at startup and every 60 seconds while open.
- Add new entries automatically with original application icons.
- Refresh immediately or add an EXE / shortcut manually.
- Open headphones, microphone, sound devices, volume mixer, and microphone permissions.
- Search, filter, and launch apps from a dark card interface.
- Preserve shortcut arguments and merge duplicate entries.

Detection depends on application names and product metadata. Apps that cannot be identified can be added manually. Device vendor software must already be installed.

## Verification

Tested discovery of a simulated new app through a real shortcut, icon loading, argument preservation, repeated scans, removal of missing entries, search, filters, and compact layouts. External vendor apps were not launched during the automated checks.
